# EasyRussia

Небольшой Windows GUI на Rust для работы с официальным релизом [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).

## Возможности

- Проверка последнего релиза GitHub и загрузка ZIP-архива.
- Проверка обновления при запуске; уже установленная версия повторно не скачивается.
- Проверка заявленного GitHub размера, ограничение размера распаковки и защита от путей архива за пределами папки установки.
- Запуск штатного PowerShell-тестера Flowseal и чтение сохранённого им `Best config`.
- Тёмный интерфейс со списком, фильтром и быстрым переключением стратегий.
- Системный трей с меню управления и вложенным списком профилей.
- Прямой запуск `winws.exe` с аргументами выбранной стратегии без окна `cmd.exe`.
- Остановка стратегии, а также открытие штатного меню системной службы.
- Включение и отключение автозапуска самого EasyRussia через HKCU `Run`.

Автозапуск приложения не устанавливает системную службу. Чтобы обход запускался до входа в систему, используйте штатный пункт установки службы Flowseal; Windows запросит необходимые права. Релизы содержат исполняемые и системные файлы третьей стороны: проверяйте их перед запуском. Обновление загружает релиз в отдельную папку версии и не запускает его автоматически.

## Сборка

Установите Rust stable и соберите приложение на Windows:

```powershell
cargo build --release
```

Приложение хранит загрузки в `%LOCALAPPDATA%\EasyRussia\releases`.
